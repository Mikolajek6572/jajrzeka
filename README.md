# Jajrzeka

Plugin na Purpur/Paper 1.21.11 - napoj **Jajrzeka** o smaku Jablko Brzoskwinia z wlasna tekstura

![napoj](narzedzia/podglad_3d.png)

## Crafting
```
diament  diament         diament
zloto    butelka wody    wiadro wody
-        jablko          -
```

## Komendy
- `/jajrzeka daj [gracz] [ilosc]` - daje napoj (op)
- `/jajrzeka paczka` - wysyla paczke z tekstura jeszcze raz

Po wypiciu: Regeneracja III, Szybkosc II, Wyskok, Absorpcja i najedzenie. Jest tez wersja jako mod Fabric (jar w wydaniach)

Paczka z tekstura (`Jajrzeka-paczka.zip`) pobiera sie z tego repo, efekty napoju ustawisz w `config.yml`
